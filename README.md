# Imee V. Necesito — personal website

This is a responsive, single-page portfolio starter for GitHub Pages.

## Publish it

1. Create a **public** repository named exactly `imee-necesito.github.io` under the GitHub account `imee-necesito`.
2. Upload `index.html`, `style.css`, and this `README.md` to the repository's root (top level).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes, then visit `https://imee-necesito.github.io/`.

## Before publishing

- Verify all role titles and dates.
- Add your preferred profile photo if desired (this template uses an abstract CSS illustration instead).
- Add your Google Scholar, ORCID, LinkedIn, GitHub, and publication links where appropriate.
- Consider whether you want your email address publicly visible.
- This site is a recreation, not an automatic import of Google Sites. Keep your original Google Sites page online until the new one is checked.

The page uses Google Fonts via an external stylesheet; the rest of the layout is local HTML/CSS.
